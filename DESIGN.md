# Wesan site design

Timeless, engineering-first. The site presents software the way a launch provider presents hardware: full-bleed imagery, few words, large calm type, one clear action.

## Themes

Two modes, both first-class. The default follows the OS; the footer switch (`auto / light / dark`) stores an override in `localStorage` and sets `data-theme` on `<html>`.

| Token | Light | Dark | Role |
|---|---|---|---|
| `--paper` | `#f1f2f4` | `#15171b` | page ground |
| `--paper-2` | `#e7e9ec` | `#1b1e23` | raised band, footer |
| `--paper-3` | `#fafbfc` | `#22252b` | panel, card |
| `--ink` | `#101317` | `#eceef1` | primary text, solid button |
| `--ink-2` / `--ink-3` | `#33373e` / `#5f646c` | `#c6cad0` / `#959aa2` | body / secondary |
| `--accent` | `#35577f` | `#a7c2e4` | focus, selection, labels only |

Dark is graphite, never pure black. Every section shares the theme ground; there are no inverted bands.

## Type

- **Barlow** 400/500/600 for everything. Display and section headings are uppercase, weight 500, tight leading (`.h-display`, `.h-1`, `.h-2`).
- **JetBrains Mono** only for numbers, dates, codes and small telemetry labels.
- Body copy stays sentence case, 16px base, max 52 to 65ch.

## Imagery: 1-bit dither

All pictures are generated by `app/_components/dither-shader.ts` (WebGL, Bayer 8x8). No stock photos.

- Scenes: `horizon` (planet limb), `ridges` (receding ridgelines), `orbit` (ringed sphere), `swell` (two-source interference).
- `Photo` maps its `tone` to a scene via `TONE_SCENE`; static images render through one shared offscreen context (`DitherStill`).
- Only the home hero animates (`DitherField`): pointer moves the light, pauses offscreen, renders one still frame under reduced motion.
- Colors come from `--dither-ink` / `--dither-ground`, so imagery repaints with the theme. Light mode reads as a halftone print, dark mode as a night photograph.

## Glass

Glass is reserved for UI floating over dither: nav, hero telemetry, chips on imagery, bottom HUD. Recipe: `.glass` (translucent `--glass-bg`, 18px blur, 1px `--glass-line`, inner top highlight, soft shadow). Never use it on plain grounds.

## Components

- Buttons: uppercase Barlow 600, 1.5px border, 2px radius. `.solid` inverts on hover. Press moves 1px, the arrow slides 3px.
- Focus: 2px accent outline, 3px offset, everywhere.
- Active nav item: 1px underline.
- Motion: ease-out `cubic-bezier(0.2, 0.7, 0.3, 1)`, UI transitions at or under 300ms.
